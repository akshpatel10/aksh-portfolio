## Running Locally

Open `index.html` in a browser. No server or build step required.

```bash
# Optional: use any static server
npx serve .
# or
python -m http.server 8080
```

---

## GitHub Pages Deployment

The site is deployed via GitHub Pages from the `main` branch root.

1. Push to `main`
2. Go to **Settings → Pages → Source: Deploy from branch → main / root**
3. Site is live at `https://akshpatel10.github.io/aksh-portfolio/`

All asset paths use relative paths (`./css/style.css`) to work correctly under the repository sub-path.
